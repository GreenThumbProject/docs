# GreenThumb

**An automated growing system for controlled-environment plant production and consistent, research-grade data collection.**

<center><img src="assets/images/greenthumb-logo.png" alt="GreenThumb logo" width="300"></center>

## What is GreenThumb?

GreenThumb runs small indoor growing units automatically and records how each crop develops. Every unit is a node that measures its environment, controls lights, airflow, water and nutrients, and photographs the plants. A shared cloud platform brings the data from every node together.

The aim is data that is consistent from one unit to the next, so cultivation results can be compared, reproduced and eventually used to train models that optimize growth.

## Origin

GreenThumb began in 2025 as a 12-month PIBITI undergraduate research project at Insper. The research phase closed in August 2026; the system is now being developed further as a startup.

## What it does

- **Monitors the environment:** air temperature, humidity, pressure and light; water temperature, level, pH and nutrient concentration.
- **Controls the unit:** grow light, ventilation, water circulation and nutrient dosing, driven by crop-specific rules.
- **Photographs the plants** on a schedule, building an image record of each cultivation.
- **Keeps working offline:** each node runs on its own and syncs with the cloud when it can.
- **Scales by adding nodes:** every unit is identical, so more units mean more comparable data.
