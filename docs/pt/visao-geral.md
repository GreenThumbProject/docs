# Visão geral

**Um sistema automatizado de cultivo em ambiente controlado, com coleta de dados consistente e de qualidade para pesquisa.**

## O que é o GreenThumb?

O GreenThumb opera pequenas unidades de cultivo indoor de forma automática e registra como cada cultura se desenvolve. Cada unidade é um nó que mede o ambiente, controla luz, ventilação, água e nutrientes, e fotografa as plantas. Uma plataforma em nuvem reúne os dados de todos os nós.

O objetivo são dados consistentes entre unidades, para que os resultados de cultivo possam ser comparados, reproduzidos e, no futuro, usados para treinar modelos que otimizem o crescimento.

## Origem

O GreenThumb começou em 2025 como um projeto PIBITI de iniciação tecnológica de 12 meses no Insper. A fase de pesquisa terminou em agosto de 2026; o sistema segue em desenvolvimento como startup.

## O que ele faz

- **Monitora o ambiente:** temperatura, umidade, pressão e luz do ar; temperatura, nível, pH e concentração de nutrientes da água.
- **Controla a unidade:** luz de cultivo, ventilação, circulação de água e dosagem de nutrientes, com regras específicas para cada cultura.
- **Fotografa as plantas** periodicamente, formando um registro visual de cada cultivo.
- **Funciona offline:** cada nó opera sozinho e sincroniza com a nuvem quando possível.
- **Escala com novos nós:** todas as unidades são iguais, então mais unidades geram mais dados comparáveis.
