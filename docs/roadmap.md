# Roadmap

- [x] Autonomous node: environmental monitoring, scheduled photos and rule-based control
- [x] Automated photoperiod and nutrient dosing with safety limits
- [x] pH and nutrient-concentration sensing
- [x] Offline-first sync to a self-hosted cloud platform
- [x] Multi-device management in a web dashboard (not public yet)
